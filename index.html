These elements would need to be scoped and approved before live deployment.

Internal MAP rules and exceptionsSupplied by the owner of the policy; legal review as appropriate.
2
Retailer price feed or lawful collectionAPI, data provider or site-approved connector; scheduled server jobs.
3
Evidence and identity matchingExact SKU/colour, coupons, dates, screenshot, timestamp.
4
Secure reporting and workflowAccess controls, alerts, escalation, authorized follow-up.
Static GitHub Pages limitation: Clicking “Run Comparison” recalculates the data already loaded in the page. It does not crawl retailers, scrape web pages or fetch up-to-date prices. A production version needs a backend service or external monitoring API. Be careful with Canadian competition law: a system should flag possible exceptions for authorized review, not automatically impose retailer pricing rules.
